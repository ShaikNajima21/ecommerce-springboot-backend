# E-Commerce Spring Boot Backend

This is a backend REST API project for an E-commerce platform built using Spring Boot and MySQL.

## Features
- User Registration
- Product Management
- Cart System
- Order System
- REST APIs
- MySQL Database Integration

## Technologies Used
- Java
- Spring Boot
- MySQL
- Maven
- REST API

## Example JSON Request

Add Product

{
 "name": "Laptop",
 "description": "Gaming Laptop",
 "price": 75000
}

Add to Cart

{
 "userId": 1,
 "productId": 2,
 "quantity": 1
}

Place Order

{
 "userId": 1,
 "productId": 2,
 "quantity": 1,
 "totalPrice": 20000
}
